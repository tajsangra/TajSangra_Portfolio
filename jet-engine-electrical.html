01 / OVERVIEW

Project Overview

The electrical subsystem brings the engine's supporting hardware under one controllable system. The enclosure houses the controller, switching hardware, motor driver, display, and supporting electronics, while external ignition and sensing hardware connects to the engine test setup.

System goals

Centralized electrical control for engine testing.

The system combines low-voltage logic with higher-current loads and ignition hardware. Keeping the electronics in a dedicated enclosure makes the bench setup easier to operate, troubleshoot, and expand.

This page is structured so each subsystem can be documented independently as testing continues.

02 / SYSTEM

Electrical System

The controls are divided into logic, switching, motor drive, ignition, sensing, and user-interface functions.

01

Controller

Runs the system logic and coordinates sensor inputs, display outputs, and control commands.

02

Power Switching

Relay and driver hardware separate low-voltage control signals from higher-current electrical loads.

03

Ignition

High-voltage ignition hardware provides the spark required during engine startup.

04

Sensing

RPM sensing provides rotational-speed feedback during testing and operation.
